# TheRealCam

Android-камера с **локальным ИИ, который учится только на снимках и оценках своего владельца**.
Модель создаётся с нуля, без чужих весов и облака. Она не перерисовывает кадр, а подбирает
параметры съёмки (выдержку, ISO, число кадров, фокус) и честно сводит серию реальных кадров.

В одном APK два приложения:

| Иконка | Что это |
|---|---|
| **TheRealCam** | камера: режимы Авто / Ручной / AI, серии кадров, сбор датасета |
| **Real Галерея** | снимки и серии, оценка 1–10 по критериям, категории со значками |

Для ПК (Linux / Windows) есть **тренер** ([`trainer/`](trainer/)): он обучает и дообучает модели
на выгруженном датасете. Работает на CPU, с CUDA быстрее.

## Структура

```
android/   — приложение (Kotlin, Jetpack Compose, Camera2, Room); без интернета и Google-сервисов
trainer/   — тренер моделей (Python + PyTorch, CLI и GUI на tkinter)
docs/      — концепция и форматы: датасет, файл модели .trcm, признаки сцены
testdata/  — эталонная модель и векторы: тест приложения сверяет Kotlin-инференс с тренером
scripts/   — установка JDK и Android SDK для сборки на Linux
```

* [`docs/CONCEPT.md`](docs/CONCEPT.md) — идея, режимы, профили съёмки, границы «честности»
* [`docs/DATASET_FORMAT.md`](docs/DATASET_FORMAT.md) — что и как пишется в датасет
* [`docs/MODEL_FORMAT.md`](docs/MODEL_FORMAT.md) — формат `.trcm`, операции графа, 33 признака сцены

## Как получить APK

**Готовый.** Каждый push собирается в GitHub Actions (workflow `build`). Во вкладке *Actions* →
последний запуск → артефакт **TheRealCam-apk** (`app-debug.apk` и `app-release.apk`).
Оба подписаны общим debug-ключом из репозитория, поэтому новые сборки ставятся поверх старых.

**Самому** (нужны JDK 17 и Android SDK 35; на Linux их ставит `scripts/setup-dev-env.sh`):

```bash
cd android
./gradlew :app:assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest      # юнит-тесты, включая сверку с эталоном тренера
```

Минимум — Android 8.0 (API 26). Ручная выдержка и ISO доступны, если камера телефона поддерживает
`MANUAL_SENSOR`. На самых простых (LEGACY) камерах работают авто-экспозиция с EV, серии и AI-категории.

## Как пользоваться

1. **Первый запуск:** приложение предложит собирать свой датасет (со списком всего, что записывается)
   и/или загрузить модель `.trcm` от другого пользователя. Это можно поменять позже в настройках.
   **Включить сбор датасета** можно и потом: Настройки → «Сбор датасета». Откроется список всего, что записывается.
   Данные хранятся только на телефоне: у приложения нет разрешения на интернет.
2. **Создать категории:** Настройки или Галерея → Категории. Это то, что вы снимаете («Звёзды на даче»,
   «Луна», «Облака»). Каждой категории назначается встроенный значок. Значок задаёт профиль
   сведения серии: звёзды — без выбросов, луна — самые резкие кадры, следы — максимум и т.д.
3. **Снимать как обычно** в режимах Авто и Ручной. Объективы переключаются кнопками над спуском
   (`0.6` — ультраширик, `1×` — основная, `2` — цифровой зум, `3` — телевик, цветок — макро), зум — жестом
   двумя пальцами. Объективы определяются автоматически по фокусному расстоянию и размеру сенсора; их список
   с названиями есть в Настройках → Камера. Xiaomi/Redmi/POCO прячут ультраширик и макро от сторонних
   приложений: приложение ищет их по номерам камер, а с root (Про-режим) открывает гарантированно.
   В ручном режиме: ISO, выдержка, фокус (AF / ∞ / дистанция),
   баланс белого, EV, **число кадров и способ сведения**. Над спуском можно заранее выбрать категорию.
   Значок штатива загорается, если выдержка требует неподвижности. Он зелёный, когда телефон
   действительно неподвижен (по гироскопу). Что делает каждая кнопка — Настройки → «Руководство» или «?».
   **Режим СЦЕНЫ** — пресеты одной кнопкой: ночь, облака, закат, луна, звёзды, следы света, вода,
   движение, документ.
4. **Звёзды — режим АСТРО:** поставить телефон на штатив или опору, выбрать время снимка (1–30 минут,
   по умолчанию 4) и нажать спуск. Выдержку кадра, ISO и число кадров камера считает сама и показывает
   план, например `15 × 16с · ISO1600 · ∞ · ≈4 мин 7 с`. Через 3 с начинается серия; на экране видно,
   сколько осталось, а голос каждые 30 с говорит «Осталось 3 минуты» (выключается значком динамика или
   в настройках; нужен русский голос в системном синтезаторе речи). Кадры, засвеченные фарами,
   выбрасываются, самолёты и спутники вычищаются по пикселям. Повторное нажатие спуска останавливает
   серию и сводит уже снятые кадры.
5. **Оценить снимки:** сразу после съёмки или в Real Галерее. Нужны общая оценка 1–10, яркость, резкость,
   шум, цвет, смаз и категория. **Только полностью оценённый снимок попадает в датасет.**
   Кадры серии можно открыть и оценить по отдельности.
6. **Выгрузить датасет:** Настройки → «Экспорт ZIP» (минимум 150 оценённых снимков, лучше 2000+).
   Можно и скопировать папку `Android/data/com.therealcam/files/TheRealCam/dataset` по USB.
7. **Обучить модель на ПК:** см. [`trainer/README.md`](trainer/README.md). Готовый тренер без установки Python
   собирается в GitHub Actions (workflow `trainer-bin`): артефакты **TheRealCamTrainer-Windows** и
   **TheRealCamTrainer-Linux** — папка с `therealcam-trainer-gui` (окно) и `therealcam-trainer` (командная строка).
   Из исходников:
   ```bash
   python -m therealcam_trainer inspect-dataset dataset.zip
   python -m therealcam_trainer train dataset.zip -o my-model.trcm
   python -m therealcam_trainer finetune new_dataset.zip --base my-model.trcm -o my-model-v2.trcm
   python -m therealcam_trainer gui
   ```
8. **Загрузить модель:** скопировать `.trcm` на телефон → Настройки → «Загрузить модель» → выбрать её.
   Моделью можно делиться с другими. Чужую модель можно дообучить на своём датасете.
9. **Режим AI:** камера раз в полсекунды смотрит на сцену и датчики и показывает 1–3 значка вероятных
   категорий с процентами и план съёмки (например `12×4с · ISO1600 · ∞`). Нажатие на значок
   говорит ИИ, что именно вы снимаете.

## Что делает ИИ, а что нет

* **Делает:** определяет категорию сцены; для неё предсказывает выдержку, ISO, число кадров,
  фокус на ∞ и EV (как вы сами снимали и оценивали похожие сцены). Во время серии в режиме AI первые
  1–2 кадра служат замером: по реальной гистограмме и гироскопу ИИ поправляет выдержку и ISO
  остальных кадров (пересвеченная луна — кадры короче; пересвеченные облака — ниже ISO; засвеченное
  небо при съёмке звёзд — темнее; телефон трясётся — короче выдержка и выше ISO). Замерочные кадры
  остаются в серии и датасете, но в сведение не идут: все сводимые кадры сняты с одинаковыми настройками.
  В ручном режиме ваши настройки не меняются.
* **Сведение серии без нейросетей:** выравнивание сдвигом, отбраковка кадров со смазом (по гироскопу)
  и засветкой (робастный z-score яркости), попиксельное sigma-clipping против самолётов, спутников и фар,
  отбор самых резких кадров для луны, максимум для световых следов.
* **Не делает:** не дорисовывает, не повышает резкость, не применяет нейросетевые фильтры.

## Статус

Проверено в этом репозитории: сборка debug/release APK, юнит-тесты интерпретатора модели
(в том числе сверка с эталонными векторами тренера, допуск 1e-4), признаков сцены и сведения серий,
тесты тренера.

**Не проверено на реальном телефоне**: в среде разработки нет устройства и эмулятора с камерой.
Поведение Camera2 на конкретных моделях (особенно бюджетных), длинные выдержки и производительность
сведения 12 МП нужно проверить на железе. Если что-то не работает, пишите модель телефона.
