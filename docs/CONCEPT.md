# TheRealCam — концепция

## Главная идея

Камера, у которой есть **свой маленький ИИ, обученный с нуля только на снимках владельца**.
ИИ не дорисовывает, не «улучшает» и не генерирует пиксели. Он делает то же, что сделал бы
опытный фотограф с этим телефоном:

1. понимает сцену (день/ночь, звёзды, луна, облака, город ночью, портрет…);
2. выбирает параметры съёмки (выдержка, ISO, число кадров, фокус);
3. честно снимает серию и сводит её: выравнивание, отбраковка кадров и пикселей-выбросов, усреднение.

Пример: астросъёмка. Телефон делает серию промежуточных кадров. Машина, засветившая объектив,
даёт кадр-выброс по яркости, и такой кадр выбрасывается целиком. Самолёт или спутник — это выброс
в отдельных пикселях, такие пиксели отсекаются sigma-clipping. Звёзды есть во всех кадрах,
поэтому остаются. Результат: реальные фотоны, меньше шума, никакой дорисовки.

## Приложения в одном APK

* **TheRealCam** — камера.
* **Real Галерея** — просмотр, серии, оценки, категории, датасет.

Это две launcher-активити в одном APK с разными `taskAffinity`, поэтому в лаунчере две иконки.

## Режимы камеры

| Режим | Что делает |
|---|---|
| **Авто** | Обычная съёмка: AE/AF/AWB, компенсация экспозиции. |
| **Ручной** | ISO, выдержка, фокус (авто / ∞ / дистанция), баланс белого, EV, **серия** (число кадров) и **способ сведения**. Всё, что выставил пользователь, пишется в датасет: так модель учится его привычкам. |
| **Сцены** | Пресеты одной кнопкой, модель не нужна: ночь (с рук — 8 коротких кадров), облака и закат (−0,7…−1 EV, усреднение), луна (короткие кадры при минимальном ISO, отбор резких), следы света (максимум по кадрам), вода (усреднение), движение и документ (самый резкий кадр). Каждая сцена делит экспозицию между выдержкой и ISO по своему правилу; первые кадры серии — замер. |
| **Астро** | Звёзды со штатива одной кнопкой, модель не нужна. Выбирается только общее время снимка: 1–30 минут. Выдержка кадра — самая длинная, при которой звёзды ещё точки (правило NPF по фокусному, диафрагме и размеру пикселя, не больше 16 с и не больше предела сенсора), ISO — по замеру превью, фокус на ∞, задержка 3 с. Первые кадры — замер: засвеченное городом или Луной небо снимается темнее. Кадры, засвеченные фарами, выбрасываются целиком, самолёты и спутники — по пикселям. На экране и голосом (каждые 30 с, отключается) — сколько осталось. |
| **AI** | Модель раз в ~0.5 с смотрит на превью и датчики и показывает 1–3 значка вероятных сцен. Значок можно нажать, чтобы указать сцену самому. Показывается план съёмки (например `12×4с · ISO1600 · ∞`) и значок штатива: он серый, пока телефон двигается, и зелёный, когда телефон неподвижен. Во время серии первые 1–2 кадра — замер: по их гистограмме и гироскопу выдержка и ISO остальных кадров поправляются (замерочные кадры не сводятся). |

Интерфейс без всплывающих плашек: значки, короткие подписи, один слайдер параметра за раз.
Что делает каждая кнопка, расписано в приложении: Настройки → «Руководство» или «?» на экране камеры.

**Про-режим** (Настройки): шумоподавление, повышение резкости и оптический стабилизатор для снимков,
а также root-доступ к камерам. С root (Magisk / KernelSU) приложение добавляет себя в список
`vendor.camera.aux.packagelist`, которым прошивки Xiaomi и других Qualcomm-устройств скрывают
от сторонних приложений ультраширик и макро. Изменение только в памяти: пропадает после перезагрузки,
при запуске приложение повторяет его само. Без root приложение пробует найти скрытые модули по номерам камер.

## Сбор датасета

Включается в настройках. При включении показывается экран, который перечисляет **всё**, что
собирается, и запрашивает согласие. Для каждого снимка сохраняются:

* геометка (если разрешена);
* ориентация телефона (наклон, крен, азимут) по датчикам;
* гироскоп и акселерометр за ~1.5 с до кадра, во время экспозиции и 0.75 с после;
* фактические параметры кадра из `CaptureResult`: выдержка, ISO, диафрагма, фокус, баланс белого и т.д.;
* что выставил пользователь в ручном режиме;
* освещённость (датчик света), давление, высота Солнца и Луны, фаза Луны, время суток;
* превью сцены в момент нажатия и признаки сцены, которые видит модель;
* оценка пользователя: общая 1–10, критерии (яркость, резкость, шум, цвет, смаз) и категория сцены.

**В датасет попадает только снимок, оценённый по всем критериям.** До этого он лежит в `pending/`.
Минимальный датасет для обучения — **150** полностью оценённых снимков. Чем больше, тем лучше:
2000+ — хороший уровень.

Формат описан в [`DATASET_FORMAT.md`](DATASET_FORMAT.md).

## Категории и значки

Пользователь сам создаёт категории («Звёзды над дачей», «Луна», «Облака») и назначает каждой
один из ~40 встроенных значков. Значок определяет **профиль съёмки**, то есть способ сведения серии:

| Профиль | Значки (примеры) | Сведение серии |
|---|---|---|
| `astro` | звёзды, млечный путь, ночное небо | выравнивание + sigma-clipping, отбраковка засвеченных/смазанных кадров, фокус ∞ |
| `lunar` | луна | «lucky imaging»: много коротких кадров, отбор самых резких, выравнивание, усреднение |
| `sky` | облака, небо, закат | выравнивание + усреднение, низкий ISO |
| `night` | ночной город, концерт, огонь | выравнивание + sigma-clipping |
| `trails` | световые следы, звёздные треки, салют, молния | «lighten» (максимум): движущиеся огни и вспышки сохраняются |
| `long` | водопад | усреднение (эффект длинной выдержки) |
| `action` | спорт, питомцы, птицы | серия, сохраняется самый резкий кадр |
| `default` | остальное | одиночный кадр |

Модель предсказывает категорию. Если она не уверена, показываются 2–3 значка, и пользователь
нажимает нужный: например «звёзды», чтобы камера не пыталась сфокусироваться на Луне.

## Модель

* Создаётся **с нуля**: случайная инициализация, без предобученных весов и чужих данных.
* Маленькая: свёрточная сеть на миниатюре 64×64 плюс MLP на 33 признаках сцены, около 100–300 КБ.
* Выходы: вероятности категорий пользователя и параметры съёмки **для каждой категории**.
* Инференс на телефоне написан на чистом Kotlin, без TFLite и ONNX. Формат файла — `.trcm`,
  описан в [`MODEL_FORMAT.md`](MODEL_FORMAT.md).
* Моделью можно поделиться файлом. Чужую модель можно импортировать и **дообучить** на своём датасете.

## Тренер для ПК

`trainer/` — Python + PyTorch. Работает на CPU, при наличии CUDA использует GPU. Есть CLI и простой GUI.
Умеет проверять датасет, обучать с нуля, дообучать существующую `.trcm`, показывать метрики и
экспортировать модель.

## Границы честности

ИИ управляет только **параметрами съёмки** и **выбором кадров**. Сведение — это классические
детерминированные операции над реальными кадрами: сдвиг, среднее, медиана или sigma-clip, максимум.
Никаких нейросетевых фильтров, апскейла или дорисовки.
